## OCR engine (Windows build)

Tesseract OCR 5.5.4 (Apache-2.0) with these dynamically linked libraries,
taken from conda-forge builds: Leptonica (BSD-2-Clause), libtiff (libtiff
licence), libpng (libpng licence), libjpeg-turbo (IJG/BSD-3-Clause/Zlib),
giflib (MIT), libwebp (BSD-3-Clause), OpenJPEG (BSD-2-Clause), LERC
(Apache-2.0), libdeflate (MIT), zlib (Zlib), zstd (BSD-3-Clause), liblzma
(0BSD), bzip2 (bzip2 licence), lz4 (BSD-2-Clause), libarchive (BSD-2-Clause),
libxml2 (MIT), libiconv (**LGPL-2.1**, shipped as a separate replaceable
DLL), ICU 75 (Unicode/ICU licence), libcurl (curl licence), libssh2
(BSD-3-Clause), libpsl (MIT), OpenSSL 3.5 (Apache-2.0).

Tesseract links libcurl, so it *could* read images from URLs. The application
only ever gives it local temporary image files, and it runs as a local
subprocess.

Language data: `eng`, `tha` and `osd` from tesseract-ocr/tessdata_fast
(Apache-2.0).
